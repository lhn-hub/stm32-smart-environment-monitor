## 实现前待裁决约束
1. TIM4每1ms回卷，不能直接以两个CNT相减测量30ms Echo；继续使用bsp_micros()的32位时间戳差。M3明确30ms超时优先于旧38000us宏，实施时统一更新。
2. DHT11完整40位返回帧通常约3~5ms，不能整帧屏蔽中断又满足“总关中断<2ms”。现有bsp_delay_us禁止在BASEPRI/PRIMASK下调用，bsp_micros依赖TIM4中断；PRIMASK屏蔽TIM4可能导致读取循环不退出。推荐18ms用任务延时，数据段开中断、有界轮询和校验失败重试，先测50次成功率；如需更强抗抢占能力，再评估PB12边沿时间戳方案。不能未经实测声称微秒精度/成功率已满足。
3. MQ和GPIO模式雷达只有单根二值输出。断线时MCU上拉高与合法高电平可完全相同，无法保证“拔任意传感器10周期内FAULT”。不得通过长时间没有报警/无人误判故障。可确认通信失败的DHT11/超声波实施连续失败FAULT；DO通道必须明确无法独立诊断开路，或由用户另行授权硬件诊断方案。
4. 内部温度仍沿用已确认的校准未验证→FAULT，VDDA标称估算；注册为sensor不等于温度可用。

回填后先落实上述约束，再进入sensor接口、驱动最小测试、DataHub和SensorTask集成。不提前发布v0.4。
