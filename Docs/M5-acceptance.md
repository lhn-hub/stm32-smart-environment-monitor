## 已实现行为

- SG90：PA8/TIM1_CH1，PSC71/ARR19999，20ms周期；CCR按
  `500 + round(2000 * angle / 180)`计算，0/90/180分别500/1500/2500us。
  servo_write只更新0..180目标；现有软件定时器每至少50ms最多移动1度，晚回调不追赶跳角。
  0→180约9秒或更慢。启动GPIO先低，初始化后输出0度脉冲；
  本地HAL_TIM_PWM_Start实际包含TIM1 MOE使能，非仅依靠模拟桩。
- fan_set接受0..100，非阻塞提交；AlarmTask拥有风扇总线锁。
  take成功后先CCR0并刷新预装载，再配置PA5/PA7推挽、PA6输入；
  BIN2/PB13=0、BIN1/PA7=1，最后STBY/PA4=1。
  PB1/TIM3_CH4的20kHz PWM以1秒从当前CCR线性到目标，100%=CCR3600。
  运行中改目标重新开始1秒斜坡；零目标立即CCR0，下一轮AlarmTask完成
  STBY0→引脚恢复SPI复用→give。等待拿锁期间的零目标会取消启动。
- 使用同一个优先级继承mutex，SPI同任务嵌套允许，SPI/FAN跨模式嵌套拒绝。
  风扇运行期间不轮流抢占SPI；日志请求保持在4项队列内等待停止。
  LogTask每次最多等待100ms并保持心跳，未出队时的竞争不会让存储离线。
  队列满仍明确返回失败/增加dropped；不能无限缓存持续运行时的事件。
  真正的SPI超时、写入结果未知、CRC/读回失败仍进入停止写入状态，禁止盲目重试。
- 急停永久锁定到复位：风扇CCR0/STBY0、SPI禁用、蜂鸣器停、RGB熄灭、
  舵机MOE禁用。Flash后续取消片选不能把共享PA4/STBY重新拉高。
  急停不承诺机械舵机立刻回零；复位后重新发送0度，位置需实物观察。
- A通道不初始化PWMA/TIM3_CH1，PB0保持输入、PA6保持输入。
  PA6仍同接MISO/PWMA；不初始化PWMA不能证明物理A通道永久禁能。
  继续遵循已确认的共享接线方案，必须测A输出差分瞬态。
  若严格要求硬件永久禁能，应隔离TB6612的PWMA与PA6连接并将PWMA固定低，
  保留W25Q MISO与PA6连接；不能直接把共享PA6配置为输出低。

## Manual Test

进入Manual Test后，KEY1单击下一项、长按上一项；PB15确认/切换编辑，PC13返回。
KEY1从稳定按下计时1.5秒发出一次长按事件，复测请按住约2秒后松开；长按释放不会再产生单击。
Fan %和Servo deg显示Set/Out及滑杆，编辑时KEY1单击+1、长按-1，边界0..100/0..180。
READY表示非编辑，可前后切项；ADJUST表示编辑，先按PB15回到READY才能用KEY1长按切上一项。
若READY状态按住约2秒仍不切项，请保留串口的“按键=0 动作=长按/单击”日志和当时页面/项目；当前修复确认的是字体预览遮盖导航，不能据主机模型排除现场按键/供电问题。
Out表示软件输出指令，未安装角度/转速反馈，不代表实测位置或转速。
Distance每个显示帧读取DataHub，故障显示FAULT，过期显示STALE。
其后可测试Fire/Intrusion/Air/Fault/Network/Standby、Beep、RGB三色、I2C Scan和字体。
退出Manual Test请求风扇停、舵机缓慢回0、灯/蜂鸣停；急停使用bsp_emergency_stop，
不可用普通退出操作替代紧急切断。

## 双向各100次实板压测命令

使用专用压测HEX及匹配的tmp/M5-stress.axf符号，调试器Watch修改变量：

```c
m5_bench_request = 1;  /* 风扇运行中写日志，100轮 */
m5_bench_request = 2;  /* Flash事务中请求启动风扇，100轮 */
m5_bench_request = 3;  /* 中止当前测试，停止风扇 */
```

这是沿用M4的调试器命令，不是UART字符串命令；USART3继续归ESP8266。
等待“存储就绪”再执行；退出Manual Test，运行时不要同时发手动执行器/日志命令。
测试只追加EVENT_BUS_TEST，不修改KV配置；追加200条事件可能按既有环形策略淘汰最旧记录。
单方向通常超过100秒，轮内5秒超时会失败停止。

模式1：风扇升到60%→排队专用事件→确认SPI至少等待一次→停风扇/归还→
检查新序号、事件参数和模式匹配→真实0x9F读取JEDEC。
模式2：LogTask已拥有完整SPI事务时提交60%风扇目标，并**注入40ms可调度窗口**
以强制AlarmTask竞争；随后完成实际日志写入/读回→风扇获锁/缓启→停机→新读JEDEC。
两种模式逐轮检查竞争证据，未发生竞争不能算通过。JEDEC期望0xEF4017，读的不是启动缓存。
错误或中止请求停止风扇并输出统计；复位/HardFault导致没有完整统计时视为失败。

最终应出现（等待次数取实测值，每次命令单独累计）：

```text
M5 cross mode=1 pass=100/100 errors=0 jedec_errors=0 spi_waits=<至少100> fan_waits=<实测>
M5 cross mode=2 pass=100/100 errors=0 jedec_errors=0 spi_waits=<实测> fan_waits=<至少100>
```

主机状态机已得到mode1等待100次、mode2等待400次、各100/100且JEDEC错误0；
主机实际arbiter/W25Q边界模型另有两方向100/100及fresh JEDEC200/200。
这些数据仅是软件模型。实板还须确认没有误转、异常复位/HardFault，并归档串口完整统计。

## PA4/PA7及PWM截图要求

共同接地，探头接PA4(CS/STBY)、PA7(MOSI/BIN1)、PA5(SCK)、PB1(PWMB)；
另测PB13(BIN2)、PA8(servo)、PB4(buzzer)。9MHz SPI建议100MS/s以上采样；
SPI解码Mode0/MSB，保留时基、采样率、电压刻度、触发沿、日期及测试命令。
截图至少包括以下四组，不用软件绘图替代：

| 截图 | 触发/时基 | 应看到的波形 |
|---|---|---|
| 上电/复位/急停后复位 | 电源或NRST，覆盖启动全过程并另放大PA8 | PA4低、PB1无非零占空比、PB4低；PA8先低，再20ms周期/500us高脉冲；无开机RGB自检/蜂鸣 |
| 风扇启动和缓启 | PA4上升沿；另取1秒窗口和50us周期放大 | PA5停止时钟；PB13低；PA7先成为稳定高，再PA4高；PB1先0，随后20kHz占空比连续升到命令值 |
| 风扇停止/日志接续 | PA4下降沿，放大切换并保留后续SPI包 | CCR归零后STBY低；PA7先低再恢复SPI复用；之后Flash包PA4低期间有SCK/MOSI，PB1保持0；每次片选结束PA4可短暂高，不能出现风扇PWM |
| Flash中请求风扇 | 覆盖整个模式2事务及后续缓启 | Flash有效包没有被风扇抢断；PA4低时完成SPI，写入BUSY轮询允许多个片选脉冲；事务释放后才出现PA7稳定高/PA4高和PB1斜坡 |

SPI的片选高电平同时使TB6612 STBY高，因此**额外测AO1-AO2差分**
及PA6释放瞬态；B风扇没转不能证明A通道安全。用差分探头，或两路对共同GND的探头作CH1-CH2；
不要把示波器地夹接到电桥输出。应看不到A通道驱动脉冲/轴运动；出现驱动即不能通过DoD③。
同时检查GPIO交接对DHT/超声IRQ的延迟和采样成功率，不能用主机测试推断实板中断时序。
