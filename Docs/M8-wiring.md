# M8 MQ 接线：优先使用拓展板预留接口

两块模块均用 5V，不能用通用 IO3/IO4 的固定 3V3 给气敏加热器供电。
核心板继续通过 USB_UART 给拓展板供电，按下拓展板自锁开关；接线时断电。

| 模块引脚 | MQ2：通用 IO1 | MQ135：通用 IO2 |
| --- | --- | --- |
| VCC / VDD_5V | VCC0，电压选择跳帽拨到 5V | VCC1，电压选择跳帽拨到 5V |
| GND | 该接口 GND | 该接口 GND |
| DO | 经 5V→3.3V 转换后接 A12 / PA12 | 经 5V→3.3V 转换后接 A11 / PA11 |
| AO | 悬空，不接 A5 | 悬空，不接 A4 |

接口方向不同：IO1 标注顺序 A5、A12、GND、VCC0；IO2 为 VCC1、GND、A11、A4。
按丝印识别，不能凭左右顺序接线，也不能直接把整个四针模块插入接口。
本工程 A5/A4 已用于 Flash/风扇，模块 AO 会干扰该总线。
原 PB0/PB14 的 MQ 方案由本表替代；不要同时把 DO 接到旧引脚。

使用适合 LM393 开漏信号的两路电平转换板时：
HV 接拓展板 5V，LV 接拓展板 3V3，GND 与模块/拓展板共地；
MQ2 DO→HV1，LV1→A12；MQ135 DO→HV2，LV2→A11。
只有供电从预留口取出，信号经过转换板再回到同一预留接口，不需要独立电源。

模块原理图 DO 通过 10k 上拉到 5V。芯片 PA11/PA12 在数字输入模式标注 FT，
但核心板 PA12 还有 USB 上拉到 3V3 的电路，本工程保留电平转换以避免该路径回灌。
不要连接 USB_DEVICE，不要开启 USB 外设或 GPIO 内部上下拉。
`APP_MQ_DO_ENABLED=1` 是当前默认生产配置；两路 LV 输出必须先实测为正常高约 3.3V、
触发低约 0V，供电和翻转点确认后再下载。未接转换板时不要下载生产镜像。

若不使用 VCC0/VCC1，也可用拓展板预留的 5V/GND 电源排针，DO 接法不变。
两块加热器与 ESP、舵机、风扇共用电源，验收时测量 5V 是否跌落；不凭电源灯判断负载能力。
模块手册建议先预热至少 5 分钟；应用 150 秒屏蔽不能替代模块预热/老化及电位器标定。
